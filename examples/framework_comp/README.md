# Framework Comparison
 Tests performance of the ml2code output compared to other Rust frameworks

 To run copy ./export/model to this directory and patch up the input arrays the build from within ./model_test

 If you want you can download efficientnet from "https://github.com/onnx/models/raw/main/validated/vision/classification/efficientnet-lite4/model/efficientnet-lite4-11.onnx" as a test case.  Or you can use helloworld_simple.py to generate a very simple onnx file.
